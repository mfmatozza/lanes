# Your first agent

Start Claude Code in the repository. Within a second the agent shows up in the **Lanes** view in the Activity Bar, grouped under your name, with the file it is editing. Teammates' agents appear under theirs.

Lanes never refuses an edit. If two agents want the same file, one waits a moment and then carries on. Problems (an edit that could not be shared yet) are listed in the view with what to do.
