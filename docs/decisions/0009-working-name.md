# ADR-0009: "Lanes" as a working name

- **Status:** Accepted
- **Date:** 2026-10-22
- **Deciders:** @mfmatozza

## Context
We need a name for repositories, packages, commands and settings (`lanes.*`). The metaphor: every agent works in its own lane, and lanes don't cross.

## Decision
Use **Lanes** as the working name until the private beta. Before any public launch: search trademarks, check domain and Marketplace availability, then confirm or replace the name in a new ADR.

## Alternatives considered
Hivemind, Crew, Tandem, Quorum, Concert, Lease.

## Consequences
- Renaming later touches command IDs and setting keys. We'll accept that cost before the public launch, and not after.
